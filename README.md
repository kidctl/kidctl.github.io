# kidctl.github.io

The website of [kidctl](https://github.com/kidctl/kidctl), self-hosted parental control for Android phones: https://kidctl.github.io/

**[Website](https://kidctl.github.io/)** · [Source code](https://github.com/kidctl/kidctl) · [Get started](https://kidctl.github.io/start.html) · [Rules](https://kidctl.github.io/policy.html) · [FAQ](https://kidctl.github.io/faq.html) · [Privacy](https://kidctl.github.io/privacy.html)

Plain HTML and CSS, no build step and no scripts: `index.html` (the home page), `start.html` (getting started), `policy.html` (rule summary), `faq.html`, `privacy.html`, `style.css`, `favicon.svg`, and `img/` (screenshot placeholders). GitHub Pages serves `main` as is.
